# Security Policy

## Supported Versions

Only the latest release of Career Agents is actively supported with security updates.

| Version | Supported |
| ------- | --------- |
| v6.2.x  | Yes       |
| < v6.2  | No        |

## Reporting a Vulnerability

Please do not open a public issue on GitHub for security vulnerabilities. Instead, email security@career-os.dev. We will respond within 48 hours and provide a timeline for coordination.
