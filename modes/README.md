# Career-Agents Pipeline Modes

Career-Agents prompt modes provide specialized workflow execution instructions for AI coding assistants (Claude Code, Cursor, Antigravity, OpenAI Codex, OpenCode, and Gemini CLI).

## Available Modes

- `pipeline.md`: Full end-to-end application pipeline processing.
- `tracker.md`: Application status tracking and pipeline reconciliation.
- `apply.md`: Application form answers and custom questionnaire tailoring.
- `scan.md`: ATS job discovery and portal scanning.
- `cover.md`: Tailored, high-impact cover letter generation.
- `pdf.md`: ATS-compliant CV formatting and compilation.
- `interview.md`: STAR behavioral and technical interview preparation.
- `outreach.md`: Networking and recruiter outreach message creation.
- `upskill.md`: Skill gap remediation roadmap generation.
