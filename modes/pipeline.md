# Mode: Career-Agents Pipeline (`pipeline.md`)

Execute an end-to-end job application evaluation and preparation workflow:
1. Parse the target job description and company background.
2. Calculate the canonical readiness score and extract core technical competencies.
3. Generate tailored ATS CV highlights and cover letter alignment points.
4. Record the application state in `pipeline-tracker.md`.
5. Provide high-priority preparation steps for upcoming interview loops.
