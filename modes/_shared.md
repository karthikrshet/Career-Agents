# Career Agents Execution Context & Shared Rules (`_shared.md`)

When executing in any Career Agents mode:
1. **Candidate Truthfulness**: Never invent achievements, metrics, or technologies not evidenced in candidate profiles.
2. **Quantified Impact**: Prefer Google XYZ formula: "Accomplished [X] as measured by [Y] by doing [Z]".
3. **Structured Outputs**: Output responses in clean, parseable Markdown or JSON when requested.
4. **Privacy-First**: Keep all candidate PII strictly confined to local session memory.
