# career-pipeline-deep

Conducts 6-axis deep research on target employers:
1. AI & Engineering Strategy
2. Recent Tech Moves & Open-Source Contributions
3. Engineering Culture & Values
4. Key Technical Challenges & Bottlenecks
5. Competitive Positioning
6. Candidate Positioning Angle

## Usage

```bash
career-agents pipeline deep <company>
```
