## 🔍 How to Find Open Challenge Tasks

Participants can discover open tasks using GitHub issue labels:
- [`challenge-2026`](https://github.com/karthikrshet/Career-Agents/labels/challenge-2026) — All challenge issues and PRs
- [`good-first-issue`](https://github.com/karthikrshet/Career-Agents/labels/good-first-issue) — Ideal for first-time open-source contributors
- [`help-wanted`](https://github.com/karthikrshet/Career-Agents/labels/help-wanted) — Priority issues requested by maintainers
- [`bug`](https://github.com/karthikrshet/Career-Agents/labels/bug) — Confirmed bug fixes
- [`mcp`](https://github.com/karthikrshet/Career-Agents/labels/mcp) / [`cli`](https://github.com/karthikrshet/Career-Agents/labels/cli) / [`ai-agents`](https://github.com/karthikrshet/Career-Agents/labels/ai-agents) — Track-specific labels

## 📊 Pull Request Review Stages

Maintainers track active challenge contributions through official GitHub PR lifecycle statuses:
1. **Submitted / Pending Review:** Label [`challenge-review`](https://github.com/karthikrshet/Career-Agents/labels/challenge-review)
2. **Revisions Requested:** Label [`challenge-needs-changes`](https://github.com/karthikrshet/Career-Agents/labels/challenge-needs-changes)
3. **Reviewed & Merged:** Label [`challenge-valid`](https://github.com/karthikrshet/Career-Agents/labels/challenge-valid)

---

## 💡 Important Principles

- **Quality Over PR Count:** Merged contributions are evaluated based on engineering value, maintainability, testing, and real-world impact.
- **No Automated Leaderboard Farming:** Submitting superficial PRs does not improve scoring. Focus on high-value fixes and well-tested features.
