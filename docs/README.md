## About Career OS

Career OS is an open-source, AI-powered career intelligence platform built for software engineers. It combines:

- **146 specialized AI agents** across 19 career domains
- **Resume Studio** with real ATS scoring, STAR analysis, and AI rewriting
- **GitHub Analyzer** with real GitHub REST API integration
- **LinkedIn Optimizer** with headline and keyword analysis
- **Interview Lab** with STAR-scored mock interviews for 10+ top tech companies
- **Career Copilot** — a context-aware AI assistant backed by your full career data
- **Plugin Marketplace** for extending functionality
- **MCP Server** for IDE-native career intelligence (Cursor, Claude Desktop, Continue)
- **14 AI providers** including Groq (free), OpenAI, Claude, Gemini, and local options
