## 🚀 How to Participate

1. **Register** your spot at [https://luma.com/3df31stw](https://luma.com/3df31stw).
2. Read the full **[Event Guide](./contribution-challenge-2026.md)** for details on the 14 contribution tracks, evaluation matrix, and AI-assisted development policy.
3. Browse existing issues or open a proposal issue using `.github/ISSUE_TEMPLATE/challenge_contribution.yml`, `challenge_bug.yml`, or `challenge_feature.yml`.
4. Fork the repo, build your implementation, write tests, and run local validation:
   ```bash
   python scripts/generate-data.py
   python scripts/validate.py
   ```
5. Submit a Pull Request using `.github/PULL_REQUEST_TEMPLATE/contribution-challenge-2026.md`.
